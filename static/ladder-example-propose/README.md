# Synthetic slide benchmark (fictional, for demonstration only)
train.json and test.json list one record per slide image; slide is the image file name.
Slide names follow the pattern SYN-SS-PPPP-DXn.svs.
The first 11 characters (SYN-SS-PPPP) identify the patient; a patient can have several slides.
The first 6 characters (SYN-SS) identify the contributing site.
label is the diagnosis class.
