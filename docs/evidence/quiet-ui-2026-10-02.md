# Quiet workspace redesign — 2 October 2026

Asterisk's current workflow now prioritizes starting and understanding a check. The design uses system typography, white and soft-gray surfaces, a restrained green action color, and a consistent rounded control language. No external fonts, UI frameworks, or decorative image assets were added.

## Interaction changes

- The ladder defaults to the new-check workspace. Benchmark exploration and evaluation evidence have separate hash-addressable views; switching views preserves the current draft.
- Three stages replace the six-stage visual rail: Define, Review, Inspect. The actual model, measurement, confirmation, replay and save steps remain explicit.
- Claim/files collapse after definition and remain available for editing. Errors reopen their containing panel.
- The exact outbound request remains visible before inference. Once a proposal returns, attention moves to review rather than keeping the old send action in view.
- A completed definition can be reopened from the result. Results lead with the claim and finding; binding details use a disclosure that opens automatically while meaning confirmation is required.
- Witnesses, scope, exclusions, provenance and receipt origin remain accessible. The measurement engine and model prompt are unchanged.
- Saved receipts, product pages and the static public-site stylesheet share the new visual direction.

## Verification

The existing suite passed 590 Python tests (9 existing skips) and 173 JavaScript tests. Main foreground/background pairs measured between 5.56:1 and 7.90:1, exceeding AA body-text contrast. Desktop, 768-pixel and 375-pixel browser checks were performed. A loaded mobile request exposed an overflowing provider button; wrapping was fixed and the same request then measured 375 pixels of content at a 375-pixel viewport.

Browser checks covered draft retention across views, outbound preview without inference, manual definition through measurement, a subject-disjoint check remaining pending, explicit confirmation, saving and reopening the confirmed receipt, and empty console error logs. A critique pass tightened the first-screen introduction, compacted mobile navigation and corrected inherited sidebar colors. Focus rings and reduced-motion handling are retained.

This is a usability and presentation change, not a new model accuracy result or independent researcher study. No inference or Sandbox calls were needed for verification.
