# Five-minute comprehension session

Recruit a second real practitioner who has evaluated models on grouped data and did not build Asterisk. Do not show the expected answer or coach during the task. Show one completed receipt and start a timer.

Ask verbatim:

1. What did this check?
2. What did it find?
3. What is still unknown?
4. What would you do next?

Save verbatim answers and elapsed time before discussing them. Pass requires correctly explaining the checked condition, finding and remaining unknowns, without saying the tool certified the experiment. Record help requests and confusion. A failed session stays failed. An automated UI walkthrough does not count.
