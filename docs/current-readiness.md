## What exists

The supported product checks exact entity overlap in supplied split/mapping tables. The workflow includes reviewed identity bindings, Nebius trusted measurements and fresh replay, original-row witnesses, separate repair revisions and offline receipts. Preprocessing, checkpoint selection and arbitrary repository execution are not shipped categories. Human confirmation records an assumption, not independent validation.

RC7 remains an unchanged frozen fallback. The working tree includes later guided-example UI and a published-result case study; RC7 is not a freeze of those changes. 3. Test whether someone outside the build can explain the identity, excluded rows, finding and limits from a receipt. Without real participants, report usefulness unmeasured.
