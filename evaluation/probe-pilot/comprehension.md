# Five-minute comprehension check

Use two ML practitioners who did not build Asterisk. Do not simulate participants with an LLM. Show each person one real completed investigation page, independently, without coaching. Allow five minutes. Capture their words, not an inferred rating.

1. What research claim was being checked?
2. What did Asterisk actually establish, and what did it not establish?
3. Which source and executed output support that conclusion?
4. What would replaying the evidence prove? What would it leave unresolved?
5. Would you run this on a repository you work with? If yes, which task? If no, why?

Fable's engineering gate: both accurately explain the claim, finding and basis for trust; at least one would use it on their own repository. Record whether the probe needed a reviewer correction separately from whether the participant understood the page. Passing is not population-level evidence of adoption.
