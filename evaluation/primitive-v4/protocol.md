# V4 split-receipt validation protocol

V3 acceptance remains failed: 9/12 primary cases each trial; 4/6 pairs. Its cases are exposed development cases from now on. V4 is a new, entity-only product iteration with human-confirmed arguments before measurement. Preprocessing, checkpoint expansion and generated adapters are out of scope.

## Claims and thresholds, set before new cases

The hypothesis is reduced human verification effort and understandable scope, not detection novelty or superiority over a coding agent. A v4 result is conditional on the user's identity binding. Human confirmation is an assumption record, never independent scientific validation.

A freeze must precede new case authorship. Ask a different author for four entity cases with different schemas: a violation and repaired twin, a no-overlap control, an incomplete-coverage case, and a misleading plausible nonunique candidate ID distinct from the partition column. This produces five variants, each attempted twice. Missing artifacts must be labeled insufficient before execution. Record exposure, author relationship, licenses, and timestamps. Author may not run candidates against the engine while selecting them. An LLM author is allowed only with disclosure; it cannot substitute for either human reviewer.

For every attempt record the original model proposal, first preflight outcome, corrections, source citations, confirmed binding, confirmation actor type, measured result and replay. Test fixtures may simulate confirmation but MUST say automated_development_fixture. Report automated proposal quality separately from end-to-end human-assisted success. A correct result after a human correction is not an autonomous model success.

Fresh-case pass requires no false definitive, no explanation contradicting measured facts, no final wrong-binding abstention on an answerable case, correct handling of incomplete coverage, and all remote replays matching. Initial rejected proposals count as recoverable errors and must still be reported. No valid clear before recorded confirmation. Every failed attempt is retained; do not replace it with a successful rerun. No passing full release assessment without the human sessions below.

## Comparison

The fresh Codex baseline on the v3 neutral inputs is one practical comparison, not matched: model, tools, context, runtime and wall-time differ. Shared-context batching and timing gaps are disclosed. Do not compare its one trial to two Asterisk trials as equal independent samples. Label agreement and reference integrity are not independent semantic endorsement. Withdraw correctness-advantage claims if it matches or exceeds Asterisk; any verification-effort claim still needs human evidence.

If a matched experiment is later run, preregister model/access differences, the same claims/input bytes, 15 tool calls and a 10-minute wall-clock ceiling per case for BOTH systems, two fresh independent attempts, token ceiling and cost accounting. Do not call the historical v3 batch matched to that new budget. A baseline agent may not read expected labels or Asterisk output before completing artifacts.

## Real people; one consistent safety threshold

Reviewer A: a real ML practitioner who did not build this, blind to expected labels until their timestamped ratings are committed. Present six neutral case bundles plus baseline artifacts for the same cases, randomized A/B labels and presentation order. Include three violations, two confirmed/pending no-overlap cases and one insufficient case. Do not give them the strategy brief, private label map or scoring report.

Record whether the evidence supports the scoped conclusion, a reproduced witness, assumptions, elapsed verification time, assistance needed and preferred format with reason. Require ZERO unsupported definitive conclusions (this resolves Fable's conflicting zero-versus-one thresholds). At least one witness must be reproduced without builder assistance within fifteen minutes. If any definitive is unsupported, stop public reliability claims and investigate in a new development version. No averaging it away.

Reviewer B: a different real practitioner. Show one result for five minutes without coaching. Ask what was checked, what was found, what remains unknown and what they would do next. Preserve verbatim answers and elapsed time. Pass requires correct checked/found/unknown and no claim that Asterisk certified the experiment. Do not let an LLM fill these roles.

The product hypothesis remains unmeasured until the sessions occur. Continue only if comprehension passes and the evidence reviewer can reproduce a witness and states a meaningful reason to prefer the receipt. If the general agent matches output quality, position Asterisk as a consistent workflow, not a correctness advantage.
